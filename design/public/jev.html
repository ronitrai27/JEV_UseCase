Typesafe System One Decision Model

JEV USE CASE

Fast, deterministic, and calibrated probabilistic decisions on arbitrary state. Unlike generative LLMs that produce streaming text, JEV (typesafe/jev-1.13) answers typed questions about a state with calibrated mathematical probabilities.

01

What is JEV?

⚡

Not a Text Generator

This model does not generate text. It answers narrow, typed questions about a state (a string, object, or array) through OpenRouter's Decisions API (/api/alpha/decisions).

🎯

Calibrated Probabilities

Outputs mathematical confidence probabilities (0.0 to 1.0) rather than hallucinated words. Perfect for threshold-based branches (is_urgent > 0.8).

🛠️

Your Code Owns Workflow

Use it for routing, ranking, verification, and other structured decisions rather than chat. Your code owns the business logic and acts directly on typed answers.

The 3 Typed Question Primitives:

1. type: "noul"

A calibrated yes/no probability from 0 (no) to 1 (yes).

e.g. is_urgent: 0.94
2. type: "choice"

A pick from user-defined options + full probability distribution.

e.g. billing: 82%, tech: 14%, sales: 4%
3. type: "score"

A position on an ordered rubric scale.

e.g. ["Calm", "Frustrated", "Very angry"]
